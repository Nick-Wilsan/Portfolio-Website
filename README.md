# Nick Wilsan | Product Manager Portfolio

A clean, minimalist, and fully responsive personal portfolio website designed to showcase Product Management case studies, Product Requirement Documents (PRDs), and UI/UX design projects. Bridging the gap between user-centric design, technical development, and product strategy.

**🔗 Live Demo:** https://nickwilsan-portfolio.vercel.app

## ✨ Features

- **Modern & Clean UI:** Built with a minimalist aesthetic emphasizing typography and whitespace.
- **Dark/Light Mode:** Seamlessly toggle between themes for optimal viewing comfort.
- **Responsive Design:** Mobile-first approach ensuring a perfect layout across all devices (Desktop, Tablet, Mobile).
- **Micro-interactions:** Smooth animations and hover effects powered by Motion.

## 🛠️ Tech Stack

This project was bootstrapped and built using modern web technologies:

- **Framework:** [React 19](https://react.dev/) with [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Motion](https://motion.dev/)
